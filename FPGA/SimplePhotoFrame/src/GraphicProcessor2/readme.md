# 概要
拡大縮小を伴う矩形コピー機能を持つグラフィックプロセッサーである。

# 入出力 (内部バス)
|ポート名|方向|ビット幅|説明|
|---|---|---|---|
|bus_cs|入力|1|チップセレクト|
|bus_address|入力|5|レジスタアドレス|
|bus_valid|入力|1|バス有効信号|
|bus_ready|出力|1|バス準備完了信号|
|bus_write|入力|1|書き込み信号|
|bus_flush|入力|1|書き込みデータをフラッシュする信号|
|bus_wdata|入力|16|書き込みデータ|
|bus_rdata|出力|16|読み出しデータ|
|bus_rdata_valid|出力|1|読み出しデータ有効信号|

# 入出力 (SDRAM I/F)
|ポート名|方向|ビット幅|説明|
|---|---|---|---|
|sdram_address|出力|22|SDRAM アドレス|
|sdram_write|出力|1|書き込み信号|
|sdram_wdata|出力|16|書き込みデータ|
|sdram_valid|出力|1|有効信号|
|sdram_flush|出力|1|書き込みデータをフラッシュする信号|
|sdram_ready|入力|1|準備完了信号|
|sdram_rdata|入力|16|読み出しデータ|
|sdram_rdata_valid|入力|1|読み出しデータ有効信号|

sdram_valid = 1 のときに、このモジュールは SDRAMへのアクセスを要求している。
sdram_ready = 1 のときに、sdram_valid = 1 の要求が受理されたとみなす。
sdram_valid = 1 のときは、sdram_flush = 1 であれば、sdram に対してフラッシュを要求している。
sdram_valid = 1 で、sdram_flush = 0 の場合は、sdram_write が 1 なら書き込み、0 なら読み出しを要求している。

# レジスタ
|アドレス|名前|読み書き|説明|
|---|---|---|---|
|0x00|SX|RW|転送元矩形の左上の X 座標（-32768～32767）|
|0x01|SY|RW|転送元矩形の左上の Y 座標（-32768～32767）|
|0x02|SWIDTH|RW|転送元矩形の幅|
|0x03|SHEIGHT|RW|転送元矩形の高さ|
|0x04|DX|RW|転送先矩形の左上の X 座標（-32768～32767）|
|0x05|DY|RW|転送先矩形の左上の Y 座標（-32768～32767）|
|0x06|DWIDTH|RW|転送先矩形の幅|
|0x07|DHEIGHT|RW|転送先矩形の高さ|
|0x08|ROP|RW|ロジカルオペレーション|
|0x09|EXEC|W|1を書き込むと実行|
|0x09|STATUS|R|実行中は 1、完了すると 0|
|0x0A|VRAM_SADDRESS_L|RW|転送元VRAM基準アドレス[16:1] |
|0x0B|VRAM_SADDRESS_H|RW|転送元VRAM基準アドレス[22:17] |
|0x0C|VRAM_DADDRESS_L|RW|転送先VRAM基準アドレス[16:1] |
|0x0D|VRAM_DADDRESS_H|RW|転送先VRAM基準アドレス[22:17] |

# ロジカルオペレーション
|値|意味|
|---|---|
|0x0000|PUT|指定の色で塗りつぶす|
|0x0001|OR|指定の色と既存の色を OR する|
|0x0002|AND|指定の色と既存の色を AND する|
|0x0003|XOR|指定の色と既存の色を XOR する|
|0x0004|ADD|指定の色と既存の色を色成分ごとに加算する|
|0x0005|SUB|既存の色から指定の色を色成分ごとに減算する|
|0x0006|MIX|指定の色と既存の色を色成分ごとに平均する|
|0x0007|MIN|指定の色と既存の色を色成分ごとに比較して小さい方を採用する|
|0x0008|MAX|指定の色と既存の色を色成分ごとに比較して大きい方を採用する|

# サイズと座標系
水平 800画素
垂直 480画素
左上隅が (0, 0)、右下隅が (799, 479) である。
VRAM_ADDRESS で指定されている場所が、左上隅の扱いである。

16bit RGB565 形式の色を使用する。
[15:11] 赤成分
[10:5] 緑成分
[4:0] 青成分

(x,y) に対応する sdram_address は、VRAM_ADDRESS + (x + y * 1024) * 2 である。

# 制御
EXEC レジスタに 1 を書き込むと、SX, SY, SWIDTH, SHEIGHT, DX, DY, DWIDTH, DHEIGHT, COLOR, ROP, VRAM_ADDRESS_L/H の値を使って矩形コピーを開始する。
コピーが完了すると、STATUS レジスタが 0 になり、sdram_flush を要求する。

# アルゴリズム
(SX,SY) → (DX,DY) から順に処理していく。
EXEC=1 のタイミングで、水平・垂直それぞれ拡大なのか縮小なのかを調べる。
以下、水平の場合で説明する。
拡大の場合、DWIDTHをカウンターに加算し、SWIDTH 以上になったら、カウンターから SWIDTH を減算して、SX をインクリメントする。
縮小の場合、SWIDTH をカウンターに加算し、DWIDTH 以上になったら、カウンターから DWIDTH を減算して、DX をインクリメントする。
垂直も、WIDTHをHEIGHTに置き換えて同様のアルゴリズムで処理する。
(SX,SY)→(DX,DY) の転送を行う際に、ROPレジスタの値に応じて、コピー元の色とコピー先の色を組み合わせる。
